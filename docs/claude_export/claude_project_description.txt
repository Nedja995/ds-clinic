Medical Clinic App helping with AI services like gemini, chatgpt, etc models in analyzing patient's medical and hls (metahunter) documents and initial question. Then user reviewing/editing and chatting with AI Service/model to correct something in response and make better analyze.
after user practically, easy and intuitive with Tkinter GUI module 'dsclinic_gui' using MVVC architecture, responsible designed, prepare his final medical report he could export to pdf.

I am currently developing inhouse medical clinic tools using latest Python 3, Tkinter and as much standard lib as i can. I am developing it in VSCode mainly on Windows 10 but it is also compatible to MacOS, both development and distribution is cross platform. I am using pyinstaller for builds, also fpdf2, pydantic, google.genai. The 'Medical Analyzer App' making report in pdf by 'chating' with AI service (googleai gemini) to analyze input docs that are usualy medical laboratory results, other medical reports and records, and also outputs from hls (holistic) software MetaHunter. Then it send structured response with fields: { 'patient name': str, 'expert analyze summary, recommendations': str, 'critical foundings': list of objects like: { 'explaining what is bed': 'parameter unit and value' }}.
It is working well currently in CLI app but making Tkinter app (that is simple, intuitive and responsive) for running analyze then reviewing, editing and asking Ai about something specifically in analysis then to correct or improve it then reviewing and merging report before export it as pdf.
